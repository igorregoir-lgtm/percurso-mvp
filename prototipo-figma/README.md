# Percurso — protótipo Figma

Protótipo interativo mobile (390px) fiel ao design no Figma do Instituto Social Ebenézer.

## Como abrir

Abra `index.html` no navegador, ou:

```bash
python3 -m http.server 8765
```

Depois acesse http://localhost:8765

## Telas

- Entrada (Maria, Rita, Cleide)
- Hoje
- Chamada
- Folha do dia
- Olhar
- Turma
- Painel da coordenação

## Fluxo

1. Escolha Maria → Hoje → Chamada → Folha do dia
2. Registrar um olhar
3. Escolha Rita → Painel
