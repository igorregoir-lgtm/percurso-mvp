# Percurso — protótipo Figma

Protótipo interativo mobile (390px) fiel ao design no Figma do Instituto Social Ebenézer.

## Como abrir

Abra `completo.html` ou `percurso-prototipo.html` no navegador (duplo clique),
ou:

```bash
python3 -m http.server 8765
```

Acesse http://localhost:8765

## Telas

- Entrada (Maria, Rita, Cleide)
- Hoje
- Chamada
- Folha do dia
- Olhar
- Turma
- Painel da coordenação
